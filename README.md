# Spreadsheet Highlight App

A Flutter application that demonstrates a responsive, Excel-like grid interface. 

## Features
* **Assumption Cells:** Highlighted in **Yellow** to clearly indicate input values or assumptions.
* **Calculated/Verified Cells:** Highlighted in **Green** to show output or verified data points.
* **Cross-platform UI:** Adaptive grid layout working seamlessly across mobile, tablet, and desktop/web sizes.

## Tech Stack
* Flutter framework (Dart)

## Setup and Run
1. Ensure Flutter is installed on your machine.
2. Run `flutter pub get` to fetch dependencies.
3. Start the application using `flutter run`.
